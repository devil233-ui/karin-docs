网页控制台 ​

字数
810 字
阅读时间
4 分钟

欢迎来到 Karin 的网页控制台介绍！(〃'▽'〃)

🎯 快速访问 ​

启动 Karin 后，你会在控制台日志中看到类似下面的信息：

bash
[Karin][00:58:40.722][MARK] karin 启动完成: 耗时 1.20 秒...
[Karin][00:58:40.722][INFO] [server] webui 已启动 访问地址: http://127.0.0.1:7777/web
[server] http鉴权token: AffryQ
[server] ws鉴权token: FGncVt

默认情况下，网页控制台运行在:

  • 地址：http://127.0.0.1:7777/web
  • 端口：7777
  • 鉴权token: 初始化项目自动生成

🔐 登录认证 ​

友情提示

第一次登录需要输入 HTTP 认证令牌 (｀・ω・´)

认证令牌就在启动日志中的 HTTP Auth Token 字段，复制粘贴就可以啦！

修改认证令牌 ​

安全提示

如果你怀疑认证令牌已泄露，请立即修改！否则可能导致未经授权的访问 (╥﹏╥)

修改步骤：

  1. 找到项目根目录下的 .env 文件
  2. 修改 HTTP_AUTH_KEY 字段的值
  3. 重启 Karin 框架 (其实可以不重启的，Karim 会自动检测到配置文件变化~)
  4. 使用新的认证令牌登录
bash
# .env 文件示例
HTTP_AUTH_KEY=your_new_secret_key  # 修改这里的值

友情提示

  • 建议使用足够复杂的随机字符串作为认证令牌
  • 定期更换认证令牌是个好习惯 (｀・ω・´)
  • 请妥善保管认证令牌，不要分享给他人

🎮 控制台功能 ​

网页控制台提供了丰富的功能，让你可以：

  • 📊 实时监控机器人状态
  • 🛠️ 可视化配置管理
  • 📝 在线插件管理
  • 🔍 日志实时查看
  • 💬 消息记录查询
  • 🎨 主题自定义

💡 使用技巧 ​

1. 保存认证令牌 ​

可以把令牌保存在浏览器，下次就不用重复输入啦！(●'◡'●)

2. 快捷操作 ​

  • 双击日志条目可以展开详情
  • 按 Ctrl + F 快速搜索
  • 右键菜单有更多隐藏功能

3. 个性化设置 ​

可以根据个人喜好调整界面布局和主题 ヾ(≧▽≦*)o

🤔 常见问题 ​

Q: 访问不了控制台怎么办？ ​

确认以下几点：

  1. Karin 是否正常启动
  2. 端口 7777 是否被占用
  3. 防火墙是否放行

Q: 令牌输入正确但登录失败？ ​

可能是因为：

  1. 令牌过期
  2. 网络连接问题
  3. 浏览器缓存问题（试试清除缓存）

Q: 如何修改默认端口？ ​

在配置文件中.env 文件中修改 HTTP_PORT 字段即可 (｀・ω・´)
